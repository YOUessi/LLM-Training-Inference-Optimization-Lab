# Stage40: true 8B constraint-aware SFT vs pure reference SFT, untouched IFEval test

**Rationale:** Stage36 original Qwen3-8B strict Google IFEval 74.0%, naive Dolly SFT rank16 54.2%, severe repeated outputs and answer-cap hitting; simple assistant-only Dolly CE alone does not preserve verified instruction constraints. Stage38 inference-only adapter scaling is a lower-cost intervention, but not a new training method. Stage40 is a *separate controlled training algorithm test*, never reusing any Stage36/Stage38 IFEval prompt ID as a new test.

**Training source & exact source identity:** License CC BY-SA3.0 original Databricks Dolly15k (512 human instruction/response records from Stage26 train split with frozen SHA). For **each real human response**, produce 3 deterministic constraint-conditioned variants: a valid JSON object with exactly one `answer` key; an XML `<answer>` wrapper (HTML escapes actual user response); and START_ANSWER/END_ANSWER sentinels. Variant target is *algorithmically transformed original human answer*, not a human approval or hallucinated teacher label. All assistant targets use full Qwen3 no-thinking chat template and are excluded if exceeding 384 total tokens (8 exceptionally long records fall back to raw). No IFEval prompts or labels used in training. Original source identity exposed exactly once per epoch, same shuffling seed, same base/LoRA/optimizer/lr and **512 steps × effective batch2 ×2 epochs =1,024 source exposures** per arm; adjust only fraction of source samples that receive validated formatting constraint (0%,25%,50%). Run rank16 Q/V NF4 BF16 LoRA, seeds4011 and4027 across each fraction =**six frozen models**. Check train/source unique coverage, per-epoch pure Dolly96 assistant CE, peak GPU allocation/step time, SHA of saved best *Dolly validation* epoch adapter. No training on any IFEval prompt.

**Independent split:** Starting with the 541 official IFEval source Apache-2.0, exclude ALL previously examined **Stage36 96 + Stage38 dev43 + Stage38 final101 =240 keys**. Freeze new SHA-selected **dev25** and **untouched test60** in five sufficiently represented constraint families (change case, combination, detectable format, keywords and start/end), exactly 5 dev/12 test per family, before generating any new model result. This doesn't cover low-remainder tiers and is not full IFEval. Official `evaluation_lib.test_instruction_following_strict/loose` unchanged. After six training arms, evaluate original base, Stage31 old full SFT, and six new models on dev25 (max384 tokens). Predefine feasible trained arm: **strict passes ≥ original-base dev strict passes −1**, **output-cap hits ≤ original-base +2**, and **Dolly frozen validation CE at least 0.10 nats/token better than original base**. Choose minimum Dolly validation CE among feasible adapted arms. Otherwise retain unadapted base and report no viable recovery. Compare chosen to original base and old Stage31 on untouched test60 **once**, record official per-class strict/loose, cap rate and seed-stratified uncertainty. Test cannot be used to choose model, fraction or checkpoint.

**Go/no-go:** A trained model only passes if it meets both independent IFEval dev and Dolly CE guards, and the final test supports comparable obedience against base with transparent uncertainty. The internal training result alone is not proof of recovered instruction following. 60 new examples are a public *subset of the same IFEval source*, not independent human traffic or a definitive global capability verdict. Deterministic format replay could induce a new category-specific bias; negative outcomes must be reported. All GPU use under a single pinned-source `flock`, fail-closed, no overwrites, saved raw logs. Single hardware cannot validate multiGPU FSDP and this is not RLHF/GRPO.
