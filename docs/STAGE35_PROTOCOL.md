# Stage35 — independent human-authored OpenAssistant multilingual prompts vs Prefix Caching

**Before measurement:** OpenAssistant OASST1 2023-04-12 root human prompter messages (Apache-2.0). Original compressed SHA256 `621ccd86a6ef320ca4e24c137121bd4b39bcc7a0df839f0897fcc965ef2076ed`. Exactly 32 each English, Spanish and Chinese original public user messages, source-reviewed, nondeleted/nonsynthetic; exclude source PII/spam/NSFW/violence/hate/toxicity annotations, URLs/emails/phone patterns, duplicates and out-of-context records. Fixed SHA256 selection, raw user text remains **only locally in ignored Tang results**, repo contains reproducible source fetch recipe, anonymous request hashes, aggregate filters and Apache attribution. This avoids redistributing potentially private human texts.

**Causal cache ON/OFF test:** Same original human user messages, no synthetic task ID suffix; match byte-for-byte user messages within pair. Application-level common ~198-token system prompt is assigned to 0%, 50% or 100% of requests, with hot50 balanced across all 3 languages. It is deliberately engineered, not originally present in the OASST prompts. Each cache ON/OFF arm gets same system/user messages, arrival seed and order; no cross-cell cache state since server restarts for every arm. Open loop 96 offers at 8/s for 3 seeds ×3 hot shares ×2 cache settings =18 cells; additional 4/s hot50 for 3 seeds ×2 cache settings =6 cells. **24 cells and 2,304 real offers** on Qwen3-8B-AWQ, vLLM 0.19.1 RTX4090 Laptop16GiB, max-num-seqs16, GPU utilization0.82, max output128, no thinking; client max64 threads, unrelated warmup. Three seeds: 3511,3527,3559, cache order counterbalanced by reversing middle seed.

**Metrics:** output tokens/second, TTFT from scheduled request time incl executor/server waits, P95, SLO 250/500/1000/2000, all-offered denominator, explicit completion errors, P95 client executor wait, server running/waiting queue sampled Prometheus and KV cache fraction. Language-specific SLO500, response length/token-cap truncation fraction. No fixed detailed response-length gate since user prompts are unmodified; output cap-hit is explicitly reported and may affect useful tokens/s. All requests accounted, source SHA and manifest record hashes immutable, no silent drops.

**Limits:** Preserved original real human queries, but fixed equal language quotas and simulated system-prefix sharing are not a natural production traffic distribution. Hot0/hot50/hot100 prompts condition the model differently; only matched cache ON/OFF within the same mixture is causal. Public-source pretraining overlap possible; output cap128 may truncate authentic answers. Only 3 arrival seeds and ~12/24-second offered windows per cell, so uncertainty intervals exploratory; benchmark does not establish hour-scale performance or direct actual cache-hit percentages.
