# Real GPU measurements — 2026-10-26

These are measured on **NVIDIA GeForce RTX 4090 Laptop GPU** (driver **580.178.04**, PyTorch **2.10.0+cu128**, Triton **3.6.0**).
Source was **Git commit `9a84d5a`**. Data files below are raw machine-generated benchmark reports copied from Tang. Results are not invented.

## Numerical correctness and kernel timings

Times are median CUDA kernel milliseconds on the reported shape; `speedup` is **the implemented unfused PyTorch baseline / the custom Triton one-row-per-program kernel**. Both sides use equal inputs, matching final output dtype, and each run checks value tolerances.

| Shape (rows×cols, dtype) | RMSNorm PyTorch ms | RMSNorm Triton ms | RMSNorm speedup | Softmax PyTorch ms | Softmax Triton ms | Softmax speedup |
|---|---:|---:|---:|---:|---:|---:|
| 128×768, float16 | 0.02355 | 0.00614 | 3.83× | 0.01229 | 0.00614 | 2.00× |
| 128×1024, float16 | 0.02355 | 0.00584 | 4.03× | 0.01318 | 0.00576 | 2.29× |
| 128×4096, float16 | 0.03584 | 0.00818 | 4.38× | 0.01946 | 0.00819 | 2.37× |
| 256×4096, float32 | 0.03482 | 0.01814 | 1.92× | 0.01946 | 0.01824 | 1.07× |
| 32×8192, float16 | 0.02355 | 0.00614 | 3.83× | 0.01472 | 0.00717 | 2.05× |

All 10 comparisons above passed PyTorch numerical validation. These results are NOT representative of attention kernels, fused inference engines, different GPU families, or CUDA graph / `torch.compile` comparisons. Small shapes can be dominated by framework/kernel launch overhead.

**Pinned benchmark timings:** `warmup_ms=75`, `rep_ms=150` except the 128×1024 FP16 smoke (same settings); seed 42; see JSON files for measured P95, max absolute error and git commit.
