# Stage25 frozen multi-factor Qwen3-8B-AWQ serving experiment

**Status: pre-run protocol, NOT a measured result.** Single Tang RTX 4090 Laptop 16GiB GPU, Qwen3-8B-AWQ FP16 compute served by vLLM0.19.1, local-only 8026, no thinking. The experiment has 22 fixed cells × 24 unique requests = **528 offered**. Two never-before-used stdlib module corpora (PSF License) are deliberately engineered to share a long identical prefix or to use unique prefixes, in four Qwen3-calibrated context buckets (~410/760/1160/1610 input tokens). Source IDs and manifest hashes are fixed before the GPU run. Arrival seeds 9401,9409; randomized fixed-window 8 and 16 offered requests/s, not an unconditioned Poisson process.

**Primary factorial:** max-seqs 8/16 × prefix cache off/on × 2 rates × 2 seeds (16 real cases) all with shared-prefix 128 output cap, default `gpu-memory-utilization=0.82`. **Controls:** two distinct-prefix 16/s cases (cache off/on), two 256-output-cap cases under cap16/cache off, and two reduced memory-utilization (0.70 vs .82) cap16/cache off 16/s cases (6 more). These are separate engine restarts and sequential, never concurrent GPU jobs. Every output retains total offered/completed/errors, first-content SSE TTFT all-offered 250/500/1000ms, p95, useful decoded tokens/s, client scheduling wait, real vLLM running/waiting gauges and KV cache fraction, exact model/driver/git SHA. No silent dropping. All strict hashes and quality gates must pass; failed cases are preserved and excluded from success claims.

Hypotheses to test, **not assumed**: (1) higher server max concurrency improves useful throughput with possible higher TTFT; (2) prefix caching helps shared-prefix more than distinct-prefix; (3) 256-token output or smaller KV budget shifts SLO/queue frontier. Candidate recommendations require paired independent seeds and clear tradeoff, not an unpaired single best cell. Source must match manually approved SHA exactly, run from a detached worktree; lock shared with training/kernels, and abort on another GPU process or preexisting port. Do not promote a tuning candidate as production-quality from two arrival seeds.
