# Stage36: independent, officially scored Google IFEval instruction-following comparison

**Frozen before generation**: Original `google/IFEval` 541 Apache-2.0 licensed verifiable-instruction records, official original JSONL SHA256 `6a85310ca8ce15eff755aa08a3a4ff931c7e273e7515ebb3c492ea85fd8288f2`. Fixed deterministic 96 prompts balanced across nine first-level instruction families using SHA256 rank, never inspecting model outputs. The subset intentionally excludes number-of-sentences instructions when local NLTK Punkt was initially unavailable (original pre-registered rule) and requested *at least* >175-word outputs incompatible with max384 tokens. We subsequently installed the **unaltered official NLTK Punkt Tab** in a non-world-writable folder, but **did not change the frozen subset**, avoiding selective cherry-picking. This is a self-defined feasible *subset*, not the official 541-prompt IFEval leaderboard score.

**Official evaluator:** unmodified `google-research/google-research/instruction_following_eval` Apache-2.0 code pinned to Git commit `7e672ccbb111603f237a3daed2f98dccd9300023` in `third_party/ifeval/google_research/instruction_following_eval/` (LICENSE retained); Python `absl-py`, `langdetect`, `nltk`, `immutabledict`. Compute both official strict/loose rule checkers, prompt-level all-instructions-correct accuracy and individual-instruction accuracy, plus per-tier false results. Fix `langdetect.DetectorFactory.seed=0` for reproducibility. No invented handcrafted grading logic. Score generated text from identical frozen prompts.

**Three independent model conditions:** Qwen3-8B BF16 NF4 base, validation-selected Stage26 short rank16 QLoRA, and validation-selected Stage31 full512 rank16 seed3127 epoch1 QLoRA. Models already frozen, no training, no benchmark-driven model selection. Use Qwen3 no-thinking template, greedy no sampling, max384 generated tokens (and <=2048 total context), same original 96 prompts, `max_new_tokens=384`. Save actual generated responses, output token counts, SHA provenance, source/adapter weight hashes and official per-prompt booleans for independent regrade. Compare full-vs-short and full-vs-base via 4000 within-frozen-sample bootstrap stratified by first-level instruction family (cannot claim training-seed generalization). Record output cap-hit fraction and any constraint types excluded or regressed. Run once on real 16GiB Tang RTX4090 Laptop under source-pinned shared GPU lock and no-overwrite guards; after GPU data generation, official scorer runs CPU-only. No mask of failures or invented quality evidence.

**Go/no-go:** 96/96 complete distinct prompts, exactly 96×3 generated responses, official grader outputs both strict and loose for every originally annotated instruction; source hashes exact, no PII-unsafe data sources, all verdicts reproducible. No factual truth/human preference/safety claim from IFEval constraint-obedience, and no automatic full-benchmark leaderboard claims.
