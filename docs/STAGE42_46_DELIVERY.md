## Synthesis and priority

1. **Already genuinely done:** source-pinned GPU execution, precise base-vs-adapter and cache counterfactuals, original verified official IFEval/IFBench grading, real shared-engine AWQ+rank16-LoRA loading, real multi-seed serving load and same-source NF4/AWQ quality comparison. Raw case-level evidence and fail-closed negative runs retained.
2. **Main verified tradeoff:** the hand-coded prompt-only constraint router mitigates strict constraint regression compared with always LoRA, while retaining a large share of Dolly reference CE gain. This is a defensible *systems routing baseline*, **not** an alignment breakthrough. Its behavior on actual AWQ serving is measurably weaker than offline NF4 for strict IFBench: 18/60 to 12/60. Quantization is not the only changed variable (offline Transformers vs vLLM FP16 execution and templates), so causality is not conclusively attributed to AWQ alone.
3. **Important negative evidence:** complex IFBench strict pass rates of **30% NF4** and **20% AWQ** for router are inadequate for reliable instruction execution. Severe generation output cap hits (IFBench router 40%, actual human request serving base 93.1% at cap192) defeat any claim of complete user answers. Reference likelihood and lexical/textual agreement are not human correctness or safety.
4. **Not yet met:** production-sampled user tasks with semantic answer-quality annotation, more pretrained/model/training seeds, an end-to-end quality-aware short/long-answer serving SLO, sustained hour-scale high load, and real multi-GPU FSDP FULL_SHARD. The available Tang machine exposes only one 16GiB NVIDIA GPU. Do not claim these gates passed without new externally validated hardware/data.

**Go/no-go:** source code and measured research evidence **PASS**; **production and general instruction-quality release BLOCKED**. Next highest-value work is an actual serving A/B with matched *complete-response* quality and true external human/independent instruction tasks, not another short-window TPS-only uplift. Also reproduce NF4 vs AWQ/FP16 discrepancies under strictly aligned tokenizer, vLLM chat template and stopping semantics to locate the source of regressions. No uncontrolled background auto-execution is enabled.
