# Stage30 preregistered real 8B cold/hot prefix-mix, longer windows

**Pre-run design:** Qwen3-8B-AWQ served via local vLLM 0.19.1 on Tang NVIDIA RTX4090 Laptop 16GiB; `max-num-seqs=16`, 0.82 GPU memory target, context limit2048, prefix caching ON/OFF. 96 **unique per-arm** PSF-licensed documentation questions, four measured input-token buckets ~400/700/1000/1400, deterministic alternating label/detailed output constraints. Three new independent arrival seeds 3011/3029/3041, fixed window 8 offers/s, **96 offered/cell over 11.875 seconds (4× prior 24-request windows)**, 18 complete arms (3 seed × 3 mix × 2 cache ON/OFF) = **1,728 offered requests**. Hot-prefix share 0%,50%,100% of offers by design; 50% is balanced 24 hot of 48 label and 24 hot of 48 detailed. Hot and cold forms originate from the same source/question identity; only the leading reusable task instruction changes. Each cache ON/OFF arm and mix/seed gets a **fresh vLLM process**, warmup uses an unrelated, small prompt and does not preload the hot prefix. Start/off/on alternates across seeds to mitigate order drift. Paired arms must share exact request identities, text hashes, scheduled offsets and output-mode assignments. No request can silently be dropped, rejection counted as SLO miss, prompt token usage/length gates and server KV/queue metrics must be valid.

**Metrics:** all-offered TTFT<=250/500/1000/2000ms, p95/p99 arrival-to-first-token, real output tokens/s, client executor wait, server running/waiting peak, sampled KV occupancy; per-prefix hot/cold breakdown. Causal interpretation limited: these engineered shared-header cold/hot conditions are **not fully cold-cache user traffic**, the GPU is warmed, and the deployed model may already know stdlib docs. No direct cache hit ratio claim without counters. Report all seeds and bootstrap CI over seed-level paired differences (n=3, very wide / exploratory). Do not use per-request bootstrap as though all requests were independent experiments; do not claim general production performance.

All runs under a pinned detached Git worktree and shared GPU flock (port 8026, other GPU process detection, output no-overwrite, 300s bounded request time, cleanup on exit); fail closed and archive invalid attempts separately before revising protocol.
