# Stage30–34: complete real-GPU research batch and audit

**Measured on Tang (2026-10-30).** This report distinguishes real 8B experiments from production claims. Five independent frozen-source GPU stages executed serially on one NVIDIA RTX 4090 Laptop (16GiB); original source commits and source/checkpoint hashes are retained per stage. All raw accepted case JSONs, important logs, machine analysis, selected model adapter, SHA256 and protocol amendments are in `evidence/` and `docs/`. `README.md` and `docs/ROADMAP.md` refer here.

- [x] Stage32 original 64 identities, three model-generated answers per identity and 384 paired independent NLI directional scores; transparent contradictions and negative category results preserved.
- [x] Stage34 explicit 128 identities disjoint from all 704 previous train/validation/test records, 128×3 real CE and reference-token counts verified.
- [x] Complete Python CPU regression test suite and a dedicated archive/hash audit; original negative/invalid source experiments retained.
- [ ] **Production** sign-off: true business traffic + real cache-hit counters, hours-long multi-GPU high load, uncertainty over several independent training seeds, human/robust semantic correctness, FSDP FULL_SHARD. Not met on current hardware and data.

**Release judgment:** *research evidence PASS, production rollout BLOCKED*. The benefits observed are conditional on these benchmark inputs, not general LLM inference or alignment gains. No automatic recurring cron was enabled.
